# Roles

One note per job title you have held. A promotion is a new role. Volunteer and board roles go here too.
Each note links to the employer, the achievements and skills from that role, and any gaps about it.
The build writes these notes when you type "Build my career base".
You can edit any note here. End a line you change with "(told me" and the date, for example (told me 14 Nov 2026), and the next build keeps it.
